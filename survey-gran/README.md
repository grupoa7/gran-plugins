# Survey Gran Semanal v0.12.8

Plugin Cowork para gerar o Survey Gran semanal automaticamente. Veja `skills/survey-gran-semanal/CHANGELOG.md` para o que mudou nesta versão.

## Instalação

1. Baixar `survey-gran-v0.12.7.plugin`
2. No Cowork: Configurações → Plugins → Instalar plugin → selecionar arquivo

## Uso

Trigger natural ou comando:
- `/survey` ou "rodar Survey"
- "fechar semana Gran"
- "atualizar Survey"

Ver `skills/survey-gran-semanal/SKILL.md` para detalhes do fluxo.
