# Survey Gran Mesa Semanal v2.1.5

Plugin Cowork para gerar o Survey Gran Mesa semanal (subset Gran Mesa + Granel + Padaria). Veja `skills/survey-gran-mesa-semanal/CHANGELOG.md` para mudanças.

## Pré-requisito

Survey Gran global rodado primeiro (gera `data/base/dados_survey.json` que o Mesa lê para alinhar nomenclatura).

## Uso

`/survey-mesa` ou "rodar Survey Mesa".
