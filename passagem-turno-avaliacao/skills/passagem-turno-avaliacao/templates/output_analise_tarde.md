# Template — Análise — Encarregado Tarde/Noite

Estrutura do long_text que vai no campo `an_lise_encarregado_tarde_noite` (internal_id 429243738).

## Esqueleto

```
▸ {NOME_ENCARREGADO_TARDE_NOITE} — {pts}/{max} ({pct}%)

   {Observação opcional se houver ambiguidade ou turno único}

   Pontuação por etapa:
   {ICONE} Etapa 4 — Painel 16h:           {pts}/{max}  ({pct}%)
   {ICONE} Etapa 5 — Fechamento:           {pts}/{max}  ({pct}%)
   {marcar MELHOR/PIOR}

   ✓ O que foi bem feito:
     • {3 a 5 itens concretos}

   → O que pode aperfeiçoar:
     • {3 a 5 itens, cada um com exemplo de melhoria}
```

## Observações situacionais (incluir quando aplicável)

**Turno único (sábado/domingo/feriado):**
> Observação: {Nome} também aparece como Responsável Abertura (mesma pessoa nas duas funções — provável turno único). Detalhe completo na Análise — Encarregado Abertura.

**Ambiguidade de responsáveis:**
> Observação: {Nome A} aparece como Responsável Tarde/Noite mas {Nome B} aparece como Responsável Fechamento. Ambiguidade reportada nos Sinais de Atenção.

## Regras (idênticas ao template de Abertura)

Veja `output_analise_abertura.md` — todas as regras de redação se aplicam aqui também:
- Tom instrutivo
- 3 partes para cada apontamento crítico
- Exemplo concreto após cada "→"
- Citar perda em pontos
- Vocabulário moderado
